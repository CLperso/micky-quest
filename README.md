# Micky Quest

Appli Android d'organisation gamifiée : briefing du matin, quêtes, matrice d'Eisenhower, sessions avec pari de durée, check-ins toutes les 30 minutes (activité, humeur, énergie), repas, boissons, cycle, découvertes sur tes patterns, feu de camp du soir et replay de la journée.

- Chaque push sur `main` construit l'APK et le publie dans **Releases** (`micky-quest.apk`).
- Les données restent sur tes appareils (et dans ton dépôt privé si tu actives la synchronisation), sauf les tâches que tu envoies toi-même dans Notion.

## Synchronisation

Téléphone et tablette partagent leurs données via un dépôt GitHub privé (Réglages › Synchronisation). Les photos de repas restent sur l'appareil qui les a prises ; les pages manuscrites ne se téléchargent que sur tablette.

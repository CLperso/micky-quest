# Micky Quest

Appli Android d'organisation gamifiée : briefing du matin, quêtes, matrice d'Eisenhower, sessions avec pari de durée, check-ins toutes les 30 minutes (activité, humeur, énergie), repas, boissons, cycle, découvertes sur tes patterns, feu de camp du soir et replay de la journée.

- Chaque push sur `main` construit l'APK et le publie dans **Releases** (`micky-quest.apk`).
- Toutes les données restent sur le téléphone, sauf les tâches que tu envoies toi-même dans Notion.
